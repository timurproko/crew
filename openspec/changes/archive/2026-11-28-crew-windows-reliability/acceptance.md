# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Automatic listing and admission use one live remote HEAD advertisement rather than a stale cached default branch.
- JSON listing overlaps independent repositories with at most eight workers while preserving project-kinds v1 and live spawn authority.
- PowerShell and UTF-8 task-file input preserve multiline descriptions, while unsafe batch forwarding refuses before admission.
- Selfrepair retains the complete-suite gate with a finite sixty-minute default, bounded override and distinct failure diagnostics.
- Reported-worker settling leaves placement free, with generation revalidation before finish can stop or return a copy.
- Fresh internal repair spaces use repository directory spelling while inherited names and placement identities remain unchanged.
