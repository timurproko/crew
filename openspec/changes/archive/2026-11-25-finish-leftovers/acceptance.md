# Conditional implementation acceptance

Verdict: accepted only when an authorized human directly merges the containing exact pull-request head after required current-head validation, explicitly asks the active agent to execute that protected exact-head merge while it is currently eligible, or personally enables native auto-merge for the unchanged head and GitHub integrates it after validation succeeds.

The maintainer integration decision accepts these scenarios:
- Verified merged or closed task PRs permit ignored-only scratch disposal without force, including KEEP, sockets and nested probes.
- Unpublished commits, tracked changes, non-ignored files, open-PR scratch and unrelated terminals retain their protective refusals.
- Spawned, relaunched, handed-over and reviewer terminals retain ownership history, including replacements published during finish.
- Worker briefs place disposable output in the external task folder and require workers to stop their disposable instances.
- Finish and merged-task land report actual discarded contents once, while deferred or failed cleanup retains the copy safely.
